# Contributing / Contribuindo

## English
1. Fork and create a branch.
2. To change `review-gate`, `handoff` or the work templates, edit them in `shared/` and run `python shared/sync_shared.py`.
3. Run `python shared/validate_all.py` before opening a PR; it must pass.
4. New team? Follow [docs/create-a-team.md](docs/create-a-team.md) and add it to the table in the root README.
5. Never add invented facts, statistics or fake testimonials to examples.

## Português
1. Faça um fork e crie uma branch.
2. Para mudar `review-gate`, `handoff` ou os modelos de `work/`, edite em `shared/` e rode `python shared/sync_shared.py`.
3. Rode `python shared/validate_all.py` antes de abrir o PR; ele deve passar.
4. Novo time? Siga [docs/create-a-team.md](docs/create-a-team.md) e adicione na tabela do README da raiz.
5. Não inclua fatos, estatísticas ou depoimentos inventados em exemplos.
