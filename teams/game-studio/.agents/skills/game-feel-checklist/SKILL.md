# Skill: game-feel-checklist

Use ao projetar, implementar ou revisar mecânicas e fases.

- [ ] A ação do jogador tem resposta imediata (visual e/ou sonora)
- [ ] O jogador entende o que pode fazer e o que acabou de acontecer
- [ ] Sucesso e falha têm feedback distintos
- [ ] A dificuldade cresce em degraus compreensíveis
- [ ] O jogador sempre sabe o objetivo atual
- [ ] Não há espera longa sem interação
- [ ] Controles têm tolerância razoável (entrada antecipada, margem de erro)
- [ ] Menus e interface são utilizáveis sem tutorial externo
- [ ] Opções básicas de acessibilidade previstas (legendas, remapeamento, contraste)
- [ ] Reiniciar após falhar é rápido

Marque o que não foi possível verificar como "não verificado".
