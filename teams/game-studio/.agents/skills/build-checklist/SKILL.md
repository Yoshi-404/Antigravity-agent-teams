# Skill: build-checklist

- [ ] Build gerada do zero em ambiente limpo, seguindo o documento de build
- [ ] Jogo inicia, chega ao menu e inicia uma partida sem erros
- [ ] Save/load funciona e é compatível com o save anterior
- [ ] Nenhum crash ou perda de progresso nos testes
- [ ] Orçamento de desempenho respeitado (veja `.agents/AGENTS.md`)
- [ ] Licenças de assets de terceiros registradas
- [ ] Nenhum segredo ou chave no repositório
- [ ] Notas de versão conferidas contra o que está implementado
- [ ] Risco residual documentado
- [ ] OK do humano antes de publicar

Item reprovado = `REJEITADO` com a lista dos pendentes.
