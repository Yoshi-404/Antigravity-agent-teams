# Skill: checklist-de-conteudo

- [ ] Alinhado à estratégia e ao público do briefing
- [ ] Tom conforme `brand-voice`
- [ ] Toda afirmação factual tem respaldo (pesquisa, dados do cliente ou fonte citada)
- [ ] Nenhum depoimento, número, prêmio ou estudo inventado
- [ ] Sem plágio; fontes citadas quando houver
- [ ] Sem promessa de resultado garantido (saúde, finanças, ganhos)
- [ ] Publicidade e parcerias pagas sinalizadas como tal
- [ ] Imagens, músicas e marcas de terceiros com licença ou autorização
- [ ] Dados pessoais tratados conforme a lei aplicável (por exemplo, LGPD no Brasil); e-mails só para quem consentiu, com descadastro
- [ ] Chamada para ação clara
- [ ] Sem linguagem discriminatória ou sensacionalista

Itens em dúvida jurídica devem ser sinalizados para o humano consultar um profissional. Este checklist não é assessoria jurídica.
