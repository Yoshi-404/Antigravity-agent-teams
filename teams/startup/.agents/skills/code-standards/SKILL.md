# Skill: code-standards

- Nomes claros; funções curtas; sem código morto.
- Tratamento explícito de erros.
- Toda regra de negócio tem teste; um comando roda tudo.
- Validar toda entrada externa; consultas parametrizadas; escapar saída em HTML.
- Sem segredos no repositório.
- Dependências mínimas e mantidas.
- Commits pequenos, mensagem explicando o porquê.
- Defina limite de custo e alertas para qualquer serviço pago.
